# System Health Dashboard

A Flask-based system health dashboard demonstrating REST APIs, structured
application logging, Prometheus metrics, automated testing, Git branching,
conflict resolution, and Docker containerization.

## Features

- `/health` — application health check
- `/version` — application version
- `/environment` — runtime environment
- `/metrics` — Prometheus metrics
- Structured application logging
- Automated tests with pytest
- Git feature branches and merge-conflict resolution
- Docker containerization

## Run Locally

```bash
python3 app.py
